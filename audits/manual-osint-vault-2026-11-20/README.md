## Critérios editoriais

- O PDF foi tratado como fonte de descoberta. A marcação ‘Vault tested’, preços e alegações de privacidade não foram assumidos como certificação independente.
- Cada aprovação exigiu URL individual com resposta HTTP 200, produto ou base identificável e função relevante para investigação, dados ou verificação.
- Relações entre nomes, contas, domínios, IPs e imagens foram descritas como pistas. Correspondência não comprova identidade, propriedade, autoria ou irregularidade.
- Ferramentas de detecção de manipulação, autoria ou IA receberam aviso de que o resultado automatizado não é veredito.
- Serviços que recebem arquivos receberam alerta para material sigiloso. Extensões e bookmarklets exigem revisão de código e permissões.
- Serviços de reconhecimento facial, pessoas, credenciais e vazamentos de maior sensibilidade ficaram fora deste lote até uma análise adicional de finalidade, proveniência, retenção e falsos positivos.
- HTTP 403, 404, 400 ou 503 foi registrado como acesso inconclusivo; nenhum bloqueio foi contornado.
